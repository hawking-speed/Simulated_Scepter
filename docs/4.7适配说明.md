# 4.7 适配分支说明（adapt/game-4.7-ui）

本分支基于上游 v1.5.37，针对《崩坏：星穹铁道》4.7 版本的界面变化做了适配，并补强了长时间无人值守运行。
使用方式与上游一致（`uv sync` 后 `uv run new_gui.py`），运行前请先阅读 [README](../README.md) 的免责声明：
**米哈游禁止使用脚本，使用本软件可能导致账号被处罚甚至封禁，后果自负。**

## 适配 4.7 界面

- 前往模拟宇宙改走「星际和平指南 → 旷宇纷争 → 差分宇宙 → 前往模拟宇宙」（地图星轨航图已无法拖到空间站）。
- 扩展装置列表默认选中上次/进行中的宇宙时，自动切到「寰宇蝗灾」。
- 其他模拟宇宙有进行中的存档时，自动「快捷结束并结算」，并处理「探索中断」结算页。
- 修正星轨航图按钮的识别位置。
- 铁血战士重投界面：直接读「重投次数 N / 作弊次数 N」判断可用动作，未解锁作弊时不再卡死。
- **（测试中）**「命途狭间」：第三位面首领房觐见装置之后的新区域，按白光菱形导航、处理对话与离开。尚未充分实测。

## 无人值守

- 开局「下载初始角色」时队伍为空会自动配队（见下文）。
- 游戏掉线退出后自动重新启动；游戏无视设置以全屏启动时，自动切回 1920×1080 窗口。
- 游戏窗口移动、重建后自动同步截图与点击坐标；最小化时暂停等待。
- 寻路卡住时逐级绕障（交易房桌子等大障碍）。

## 自动配队（可选）

在 `user/team/` 下放角色头像截图，按文件名顺序上场，**1 号位是地图上平 A 开怪的角色**（推荐白厄、黄泉、银狼 LV.999）：

```
user/team/1_黄泉.png
user/team/2_银狼.png
user/team/3_xxx.png
user/team/4_xxx.png
```

头像在游戏「下载初始角色」界面截取（窗口 1920×1080 时，单个头像约 100×90 像素，包含头像上半部分即可）。
没有放模板时，会按位置选择角色列表的前 4 个。

## 开发工具

- `tool/scripts/trigger_audit.py`：在任意游戏截图上检查 `insect.json` 触发器的命中情况与疑似移位，
  游戏更新后排查卡点用：`uv run python tool/scripts/trigger_audit.py 截图.png --raw`
