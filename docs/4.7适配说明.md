# 4.7 适配分支说明（adapt/game-4.7-ui）

本分支基于上游 v1.5.37，针对《崩坏：星穹铁道》4.7 版本的界面与玩法变化做了全面适配，并新增 **货币战争 S2「入画奇航」深度策略引擎**、**黄金与机械**、**不可知域** 以及 **4 级冻屏自检与前景护栏**。
使用方式与上游一致（`uv sync` 后 `uv run new_gui.py`），运行前请先阅读 [README](../README.md) 的免责声明：
**米哈游禁止使用脚本，使用本软件可能导致账号被处罚甚至封禁，后果自负。**

## 适配 4.7 界面与寰宇蝗灾 (`core/any_fate/`)

- 前往模拟宇宙改走「星际和平指南 → 旷宇纷争 → 差分宇宙 → 前往模拟宇宙」（地图星轨航图已无法拖到空间站）。
- 扩展装置列表默认选中上次/进行中的宇宙时，自动切到「寰宇蝗灾」。
- 其他模拟宇宙有进行中的存档时，自动「快捷结束并结算」，并处理「探索中断」结算页。
- 修正星轨航图按钮的识别位置；补充「本位面挑战成功」「点击空白处关闭」触发器。
- 铁血战士重投界面：直接读「重投次数 N / 作弊次数 N」判断可用动作，未解锁作弊时不再卡死。
- **「命途狭间」**：第三位面首领房觐见装置之后的新区域，按橙色光柱掩膜导航、处理对话与离开。

## 货币战争 S2「入画奇航」专精 (`core/currency/`)

- **动态对局记忆数据库 (`MatchDatabase`, `core/currency/match_db.py`)**：实时维护棋盘前台/后台/备战席角色、星级、装备数与已穿装备、人口、金币、连胜/连败等状态并落盘。
- **全量装备库与 36 条合成路径 (`core/currency/equipment_db.py`)**：支持 8 件散件保留判定、36 组合成配方查找、主 C / 辅助 / 生存评分与 `精密拆装扳手` / `重铸熔炉` 转装规划，避免满 3 件硬拖与防御装错穿。
- **「连击阿格莱雅 / 那刻夏」专精运营 (`core/currency/combo_strategy.py`)**：内置前后台优先级、10/20/30/40/50 金币吃息控制、连胜/连败搜牌节奏、升人口与备战席溢出清理。
- **S2 流程与攻略追踪 (`core/currency/s2_actions.py`, `settings.py`)**：支持超频/常规模式、最高职级开局（`rank: "highest"`）、攻略应用后弹出的「装备追踪」二级弹窗自动勾选，以及晶球领取/装备栏扫描（兼容状态条导致的 23 像素坐标偏移）。

## 新增多宇宙模块

- **黄金与机械 (`core/gold_gears/`)**：继承棋盘系统并由 `build_nous.py` 自动从 `insect.json` 生成 `nous.json`；遇到不可知域进行中存档时写 `GG_BLOCKED.txt`（可通过 `SIMS_GG_TOOLS_DIR` 环境变量指定目录）并安全停机，不误删进度。
- **不可知域 (`core/unknowable/`)**：继承差分宇宙位面引擎并独立处理扩展装置入口、权杖/组件选择、交易/精英/谬误第四位面导航及卡死「暂离」保护。

## 无人值守与自检护栏

- 开局「下载初始角色」时按 `user/team/<序号>_*.png` 自动清空重选或默认前 4 名角色配队。
- 游戏掉线退出后自动重新启动；游戏以全屏启动时自动切回 1920×1080 窗口；窗口移动/重建自动同步坐标。
- 寻路卡住时逐级绕障（交易房桌子等大障碍）。
- **4 级冻屏/停滞自检修复 (`core/currency/automation.py`)**：基于 `96×54` 灰度摘要检测像素冻结（35s / 65s / 95s / 145s）及非战斗阶段停滞（45s / 75s / 105s / 145s），依次清理教学/统计/合成预览弹窗、重置阶段标志与收起商店、重聚焦 + `Esc` 脱困，最终无效时存图报错停机。
- **双轨让位与前景守护**：检测到 `ZZZ_RUNNING.lock`（支持 `SIMS_ZZZ_LOCK_PATH` 配置）时自动让位停机；前景非《崩坏：星穹铁道》时暂停点击等待切回。

## 自动配队（可选）

在 `user/team/` 下放角色头像截图，按文件名顺序上场，**1 号位是地图上平 A 开怪的角色**（推荐白厄、黄泉、银狼 LV.999）：

```
user/team/1_黄泉.png
user/team/2_银狼.png
user/team/3_xxx.png
user/team/4_xxx.png
```

头像在游戏「下载初始角色」界面截取（窗口 1920×1080 时，单个头像约 100×90 像素，包含头像上半部分即可）。
没有放模板时，会按位置选择角色列表的前 4 个。
